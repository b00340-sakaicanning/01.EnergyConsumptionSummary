# 作業履歴: 操作マニュアルの追加

## 実施日時
2026-10-10 18:56

## 修正理由・背景
- ユーザーより、「マニュアルを作成してほしい。作成するにあたり、カードキー管理アプリ、ロッカーキー管理アプリのマニュアルの実装内容を参照してほしい」との依頼を受けた。
- 参照した2アプリ（`02.入退出カード貸出管理(Gemini)`、`02.ロッカーキー貸出管理(Gemini)`）のマニュアルは、同じ方式で作られていた。
  - ヘッダー右上の「マニュアル」ボタンから、別タブで独立した `manual.html` を開く（GAS では `doGet` が `?page=manual` で振り分け、公開URLは `getAppUrl()` で取得）。
  - 左に追従する目次と印刷ボタン、タイトルのバナー、章ごとのカード。注釈番号を焼き込んだスクリーンショット、番号と説明の対応表、手順のリスト、注意書き3種、FAQ。
  - 画像は WebP を base64 で埋め込む（GAS には画像ファイルを置けないため）。
- 2アプリには次の問題があったため、踏襲しなかった。
  - 同じ内容を3か所（原本 HTML、GAS 用 HTML、Markdown）に持ち、手で同期している。画像の変換・埋め込みのスクリプトが残っていない。
  - 本文に Markdown の `**…**` が残り、画面にアスタリスクが表示されている。
  - 利用者向けの文章に実装用語が混ざっている。図番号に欠番がある。セットアップ手順書に `manual.html` の配置が書かれていない。

ユーザーに確認した方針:
- 成果物は HTML のみ（Markdown 版は作らない）。原本を1つ持ち、GAS 用の画像埋め込み版は `build.js` で自動生成する。
- 対象読者は現場担当者。操作中心で、管理者向けは要点（更新時の手順とシートの概要）を1章にまとめる。
- スクリーンショットは実データ（読込用データ）の画面を使う。

## 修正内容

### 1. 「マニュアル」ボタンと振り分け
- **`gas_app/index.template.html`、`gas_app/css/style.css`**: ヘッダー右側（反映状況の表示の次）に「マニュアル」ボタンを追加。本のアイコン＋「マニュアル」＋外部リンクの矢印で、3画面のどれを表示していても見える。
- **`gas_app/js/app.js`**: `openManualWindow` を追加。
  - ローカル: 同じフォルダの `manual.html` を別タブで開く。
  - GAS: `google.script.run.getAppUrl()` で公開URLを取り、`?page=manual` を付けて別タブで開く。取得に失敗した場合、URL が空だった場合、古い `Code.gs`（`getAppUrl` が無い）の場合は、現在のURLから組み立てる。
- **`gas_app/Code.gs`**: `doGet(e)` の先頭に、`?page=manual` のとき `manual.html` を返す分岐を追加。`getAppUrl()` を追加。それ以外の処理は変更していない（追加 16 行のみ）。

### 2. マニュアルの原本と生成
- **`gas_app/manual.template.html`**（新規）: マニュアルの原本。本文と専用の CSS を持ち、画像は `manual_images/` のファイルを参照する。
  - 章立て: 1. システム概要と画面構成 / 2. 使い始める前に / 3. 【電力】データの読み込みと単月の確認 / 4. 【電力】年間推移の確認 / 5. 【燃料エネルギー】 / 6. 【トータルエネルギー】 / 7. スプレッドシートへの反映と Excel エクスポート / 8. 【管理者編】更新と保守の要点 / 9. 付録・FAQ（用語8件、よくある質問8件）。
  - 図は 11 枚（【図1-1】〜【図7-1】）。
  - 構造とクラス名は参照アプリを踏襲（目次のサイドバー、印刷ボタン、バナー、章のカード、`figure-box`、`table-container`、`num-badge`、`alert-box` 3種、`faq-item`、印刷用・狭い画面用のスタイル）。配色はこのアプリのテーマ（青系）に合わせた。

## 検証結果

### 既存の3画面への影響
- 変更前後の `index.html` をヘッドレス Chrome で同じ手順で操作し（34 ステップ。電力の3ビュー、燃料エネルギー、トータルエネルギーの月別・年度推移、反映、`?app=` での起動）、各ビューの HTML、グラフのデータと軸、表、反映状況、通知を比べた。**すべて変更前と同じ**で、違いはヘッダーに「マニュアル」ボタンが増えたことだけだった。

### マニュアルの紙面（22 項目すべて OK）
- 画像 11 枚の参照がすべて実在し、未使用・重複が無い。ビルド結果に別ファイルへの参照が残っておらず、画像以外は原本と同じ。
- 外部の CSS・JavaScript・フォント・画像を参照していない。Markdown の記法（`**`）とインラインの style が無い。
- 図番号 11 件が章ごとに 1 から連番で、置かれている章と一致する。
- **図の中の番号（撮影スクリプトの注釈）と、その図に続く本文の番号が、11 図すべてで一致する。**
- 目次 32 件のリンク先がすべて存在し、見出しの番号と一致する。
- **本文で引用した画面上の文言 61 種類が、すべて実際の画面にある**（実データを読み込んだ画面の文字と突き合わせた）。
- 表示: 画像がすべて表示される。目次が左に追従し、目次のリンクで該当の見出しへ移動する。表が横にはみ出さない。印刷用の表示では目次が消え、PDF として出力できる（A4 で 22 ページ）。狭い画面では目次が上に移り、ページが横にはみ出さない。

### 「マニュアル」ボタンと振り分け（16 項目すべて OK）
- `Code.gs`（模擬の実行環境）: `?page=manual` で `manual.html` を返す。パラメータなし・引数なし・別の値・別のパラメータでは、従来どおりアプリ本体を返す。`getAppUrl()` が公開URLを返す。
- ローカル: 電力・燃料エネルギー・トータルエネルギーのどの画面でもボタンが表示され、`manual.html` を別タブで開く。元の画面は移動しない。
- GAS を模した環境（ローカル以外のホスト名で開いた場合）: 公開URLを取得できた場合は `…/exec?page=manual`、公開URLに既にパラメータがある場合は `&page=manual` を付けて開く。取得に失敗した場合・空だった場合・古い `Code.gs` の場合は、現在のURLから組み立てて開く。

## 未確認事項・注意点
- **GAS 環境では未確認。** 次の作業と確認が必要。
  1. Apps Script エディタで HTML ファイル `manual` を新規に作り、`gas_app/manual.html` の内容を貼り付ける（約 900KB あるため、貼り付けと保存に時間がかかる）。
  2. `Code.gs` と `index.html` を貼り替えて、再デプロイする。
  3. 「マニュアル」ボタンから別タブでマニュアルが開くこと、画像が表示されること、目次のリンクで移動できること、印刷ボタンで印刷の画面が開くことを確認する。
- `manual` を置かないまま「マニュアル」ボタンを押すと、エラーの画面になる。`index.html` だけを新しくして `Code.gs` が古いままの場合も、マニュアルは開けない（GAS の画面は枠の中で動くため、現在のURLから組み立てたURLでは開けない）。
- **GAS へ置くファイルが4つになった**（`Code.gs`、`Config.gs`、`index.html`、`manual.html`）。
- **マニュアルには実データの画面が載っている。** アプリのURLを知っている人は誰でも開ける（アプリ本体と同じ公開範囲）。画像は git にも入る。
- **画面を変更したら、マニュアルの該当箇所と図も直す必要がある。** 図は `node tools/capture_manual_screenshots.js` で撮り直せるが、Google Chrome、`reference/` の実データ、インターネット接続が必要。手順は `docs/05_セットアップ手順.md` の「操作マニュアルの更新」に書いた。
- `manual.html` は約 885KB で、計画時の見込み（600〜800KB）より大きい。図が 11 枚あり、4つのグラフや表を1枚に収めた縦長の図が多いため。画像の品質を 82 から 75 に下げ、表を数行だけ写すようにして、約 1,030KB から減らした。
- 計画では「スクリプトは印刷ボタンのみ」としていたが、目次のリンクで見出しへ移動する処理（数行）を追加した。GAS の画面は枠の中で表示されるため、リンクだけでは移動できない場合に備えたもの。
- 8章（管理者編）は、GAS エディタの画面を自動で撮影できないため、文章と表だけで説明している。初回セットアップの詳しい手順は `docs/05_セットアップ手順.md` にある。
- 対象外: Markdown 版・PDF ファイルの作成（PDF は印刷ボタンからブラウザで保存できる）、マニュアル内の検索。
