# 年間集計表累計修正・数値等幅フォント化・単月画面年月選択機能の追加

## 実施日時
- 2026-10-04 14:10

## 概要
ユーザーからの指摘および改善要望に基づき、以下の4つの改修を実施しました：

1. **年間集計表の「累計」計算ロジック改修および全指標への累計データ反映**:
   - `demo_annual_2024.json` および `demo_annual_2025.json` のデータ生成スクリプト（`generate_annual_demo_json.py`, `generate_exact_2025_json.py`）を更新し、電力量だけでなく、操業時間、生産本数、原単位、単位時間電力量、電力コスト等の全指標・全月度について `cumulativeTotal`（累積合計 / 累積期間平均）を計算・格納するように修正。
   - `gas_app/js/app.js` の `renderAnnualTable` においても、動的累積計算フォールバック（合算指標の累積和、および原単位・比率指標の期間平均原単位計算）を実装し、どの指標を選択しても確実に正確な累計値が表示されるように改修。

2. **数値表示の等幅（固定幅）フォント化と各桁の垂直整列**:
   - `gas_app/index.html` に Google Fonts `JetBrains Mono`（等幅フォント）をインポート。
   - `gas_app/css/style.css` の `.data-table td` に対し、`font-family: 'JetBrains Mono', 'Roboto Mono', 'SF Mono', Consolas, monospace;`、`font-variant-numeric: tabular-nums;`、`font-feature-settings: "tnum";` を指定。
   - 各数字（0〜9）の横幅が完全に均一になり、上下行で同じ桁数の数値の左端位置、カンマ、小数点がExcelのように一直線に整列して表示されるように改善。

3. **単月詳細集約画面における「表示対象年月」選択機能の追加**:
   - `gas_app/index.html` の単月画面ドロップゾーン下に、コントロールツールバー（`#monthlyYearMonthSelect`）を新設。
   - 読み込み済みの年月（例: `2025年3月度 (202503)`、`2025年4月度 (202504)` 等）をドロップダウンから選択して、対象年月のKPIカード・日別グラフ・工程比率円グラフ・日別テーブルを瞬時に切り替え表示可能に改修。

4. **データ読込後の最新月自動表示制御および直前選択年月の記憶保持**:
   - **データ読込時**: 単一月、または複数月のデータを読み込んだ際、読み込まれた月の中から**最新月（最大年月）** を自動選択して画面に即座に表示。
   - **タブ切替時 / 読込前**: 直前に表示を切り替えていた年月があればその年月を維持表示し、なければ保持データ中の最新月を表示。
