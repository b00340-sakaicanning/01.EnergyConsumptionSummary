# 作業履歴: トータルエネルギー画面の追加と表示年度の絞り込み

## 実施日時
2026-10-09 20:29

## 修正理由・背景
- ユーザーより、「エネルギー計算表の生産量＆エネルギー使用量、熱量、原単位、CO2排出量を表示するページを、トータルエネルギーページとして実装してほしい」との依頼を受けた。
- エネルギー計算表（`reference/読込用データ/かつらぎ工場エネルギー計算表_読込用.xlsx`）を調べた結果:
  - 各年度シート（2013〜2026年度の14シート）の上部に、依頼の4つのグラフ（生産量＆エネルギー使用量推移、熱量推移、原単位推移、生産液量1klあたりのCO2排出量推移）と、年間サマリー（前年度比つき）がある。
  - 必要な行は全年度にあるが、行の位置は年度によって違う（ラベルで探す必要がある）。
  - 熱量・CO2・原油換算の係数は年度によって違う（例: 電気の CO2 係数、A重油の熱量）。
  - 2023年度以降には、太陽光発電の値と「太陽光発電 無しの想定値」がある。
  - 複数年度を並べた `年度推移_予測用` シートは、2020年度までで更新が止まっている。
  - 値はエネルギー計算表だけで決まる（月報PET・ロガーデータは不要）。

ユーザーに確認した方針:
- 対象年度の月別グラフに加えて、各年度の年間値を並べた年度推移も表示する。
- CO2 のグラフは、排出量の内訳（A重油・LNG・電気）の積み上げ棒 ＋ 生産液量1klあたりの折れ線。
- データはスプレッドシートに保存する（反映・起動時の復元・エクスポート）。
- 太陽光発電「無しの想定値」は、参考として表に表示する。
- **表示する年度は、月報PETにシートがある年度だけにする。燃料エネルギーの画面も同じ基準に変更する**（計画の提示後にいただいた指示）。

## 検証結果

検証には、ヘッドレス Chrome と、**実際の `Code.gs`・`Config.gs` を Node.js 上で実行する模擬スプレッドシート**をつないだ環境を使った（ブラウザの `google.script.run` の呼び出しが模擬スプレッドシートに届き、ページを再読み込みしても保存内容が残る）。

### Excel との突合（全14年度）
アプリの計算値を、エネルギー計算表自身の行・年間サマリーと比べた。

| 比較した項目 | 結果 |
|---|---|
| 月別の原単位（162か月） | すべて一致 |
| 月別の生産液量1klあたりの CO2（162か月） | すべて一致 |
| 年間の A重油・LNG・電気・合計の熱量、原油換算量、CO2排出量（14年度） | すべて一致 |
| 太陽光無し想定の合計GJ・合計CO2・原単位・1klあたりの CO2（2023年度以降の42か月） | すべて一致 |
| 年間の生産量・原単位・CO2 の比（2019〜2026年度） | すべて一致 |
| 同（2013〜2018年度） | Excel の年間サマリーが丸めた値（生産量は整数の千ケース、原単位は小数3桁）を持っているため、差が出る（最大 0.085%）。この年度は現在の表示対象外 |
| 月別の千ケースあたりの CO2 | Excel は千ケースを整数に丸めてから割っているため、差が出る（最大 0.49%）。Excel と同じく丸めた値で割ると 162か月すべて一致 |
| 原単位の前年度比 | 2020〜2025年度は一致。2014〜2019年度は、上記の丸めの影響で差が出る（最大 0.16%）。**2026年度は不一致**（アプリ 98.3% / Excel 105.8%）。Excel の 2026年度シートの「前年」列が、2025年度ではなく 2024年度シートを参照しているため |

## 未確認事項・注意点
- **GAS 環境では未確認。** `Code.gs`・`Config.gs`・`index.html` の3ファイルを貼り替えて再デプロイしたうえで、次の確認が必要。
  - トータルエネルギー: `トータルエネルギー集約` シートの作成、反映、再読み込み後の復元と「反映済み」の表示、エクスポート（5シート）。
  - 燃料エネルギー: 表示年度が 2024〜2026年度になること、反映・復元・エクスポート。
  - 電力: 起動時の復元、反映、エクスポートが従来どおり動くこと。
  - 模擬スプレッドシートは実際の `Code.gs` を実行しているが、実際のスプレッドシートでの値の丸めや書き込み時間までは確認できていない。
- **燃料エネルギー・トータルエネルギーは、月報PETを投入しないと表示されない**（保存済みのデータを復元した場合を除く）。トータルエネルギーの値はエネルギー計算表だけで決まるが、表示する年度を決めるために月報PETが必要。
- **2023年度は表示されない。** 電力のロガーデータは 2023年度分があるが、月報PETに 2023年度のシートが無いため。月報PETに年度のシートを追加すれば表示される。
- **最初の年度（2024年度）は前年度比が出ない。** 前年度（2023年度）が表示対象外のため。
- **`燃料集約` シートに保存済みの 2013〜2023年度の行**（対象年度の変更前に反映した場合）は、画面には表示されなくなるが、シートには残り、エクスポートにも含まれる。不要ならシート上で削除する。
- **Excel の 2026年度シートの「前年」列は、2024年度シートを参照している**（2025年度シートを参照するのが正しいと思われる）。アプリは 2025年度と比べるため、2026年度の前年度比は Excel と違う値になる。Excel 側の確認をお願いしたい。
- 年度推移では、入力途中の年度（2026年度）の総量（生産数量・熱量・CO2排出量）が他の年度より小さく表示される。ラベルに月数を添えて区別している。原単位と1klあたりの CO2 は、途中の年度でも比べられる。
- 電気の熱量・CO2 は購入電力分。太陽光発電分は含まれず、参考表で「足し戻した場合」を確認できる。
- アプリは Excel が計算した値を読む。Excel を開かずに外部ツールで書き換えたファイルでは、計算結果が古いままになることがある（電力・燃料の既存の読み取りと同じ前提）。
- 対象外: 近似式による将来予測（`年度推移_予測用` シート）、`必要削減率` シート、エネルギーコスト（円/ケース）、グラフの目盛りの固定値設定。
