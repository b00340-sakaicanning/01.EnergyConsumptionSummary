## 修正理由・背景
- 現行のアプリ・ビルド・テストのいずれからも参照されていない旧ファイルが残っており、現行版と取り違える原因になっていた。
- ユーザーの確認を得たうえで、即時削除ではなくゴミ箱（`~/.Trash/`）へ移動した。

## 修正内容
1. **ゴミ箱へ移動したファイル・フォルダ**

   | 対象 | 理由 |
   |---|---|
   | `gas_app/simulate/`（`simulated_gas_output.html`、`simulated_gas_prod.html`） | 目盛り設定・ローディング・現行エクスポートを含まない旧版のシミュレーター。`build.js` やテストからの生成・参照なし |
   | `tools/`（`batch_import.py`） | ファイルを列挙して表示するだけで、集計結果を出力しないスタブ |
   | `output_batch/` | 上記スタブが作る空フォルダ |
   | `screenshot/design_preview_annual_light.html` | 参照先の CSS / JS が `screenshot/` 配下に無く、リンク切れ |
   | `plan_draft/`（`01_要件定義書.md`、`02_構築手順書.md`） | `plan/` の前段階のドラフト。内容は `plan/` と `docs/` に引き継がれている |

2. **`.gitignore` の整理**
   - 移動済みの `plan_draft` の行を外し、`.DS_Store` を追加。

## 補足
- これらに触れている `docs/` と `GEMINI.md` の記述は、整理フェーズ6でまとめて修正する。
- 元に戻す場合はゴミ箱から同じ場所へ戻す（`plan_draft/` と `output_batch/` 以外は git からも復元可能）。
