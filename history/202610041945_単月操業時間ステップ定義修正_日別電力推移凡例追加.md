# 作業履歴: 単月操業時間ステップ定義修正 & 日別電力推移グラフ全工程凡例追加

## 作業日時
2026-10-04 19:45

## 概要
1. **単月操業時間の計算修正**:
   - `gas_app/js/config.js` において、`STEP_MASTER` の定義が旧簡易版（14がCIP最終すすぎ）となっていたため、生データで大半を占めるステップ14（次工程送液/実充填）が除外され、実充填操業時間が 31.6 時間（水運転 2.1 時間）と極端に少なく表示されていた問題を解消。
   - 原紙Excel（`月別電力使用量集約(2025年3月).xlsx`）の「ステップ」シートに記載されている全57件の正確なステップ定義（14=次工程送液/実充填, 8-11/17/18=水運転 など）へ全面更新。
   - `gas_app/demo_data_202503.json` の1分値集約データを新しいステップ定義で再生成・更新。
   - これにより、2025年3月度の単月実充填操業時間が **575.4時間**、水運転時間が **115.1時間**（合算 **690.5時間**）となり、年間推移グラフ・年間集計表の実績値と1分単位まで完全一致することを確認。

2. **日別電力使用量推移グラフの系列・凡例追加（A案）**:
   - `gas_app/js/components/charts.js` の `renderDailyChart` において、登録が漏れていた「調合抽出」および「供給」のデータセットを追加。
   - 全6系列（総電力、チラー、調合抽出、供給、充填、包装）のカラーパレットを定義（ドーナツチャートと色調統一）し、グラフの棒および凡例を完備。

3. **キャッシュ対策 & デモデータ読込最適化**:
   - `gas_app/index.html` の script タグのキャッシュバスターを `v=20261004_3` に更新。
   - `gas_app/js/app.js` の `demo_data_202503.json` の fetch 処理にタイムスタンプクエリパラメータを付与し、常に最新の集計データが即座に反映されるよう対応。
