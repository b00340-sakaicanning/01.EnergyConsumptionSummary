# 作業履歴: 整理フェーズ3 未使用コードの削除

## 実施日時
2026-10-07 20:12

## 修正理由・背景
- 「呼び出し元が無い」「書き込むだけで読まれない」「到達しない」コードが残っており、今後の修正で誤って手を入れたり、実際の仕様と取り違えたりする原因になっていた。
- いずれも全ソースを grep して未参照であることを確認したうえで削除した。画面の表示・集計値・スプレッドシートへの保存内容は変わらない。

## 修正内容
1. **未使用のCDN読み込みの削除（`gas_app/index.template.html`）**
   - PapaParse の `<script>` を削除。CSV の解析は自前の `CsvParser.parseCsvLine` で行っており、`Papa` の参照はどこにも無い。

2. **GAS側の未使用定義の削除（`gas_app/Config.gs`、`gas_app/Code.gs`）**
   - `getConfig()`、`CONFIG.SHEET_NAMES.MONTHLY` / `MASTER` を削除。
   - `saveKpiSummary` の未使用変数 `water` / `fill` を削除。
   - `saveVarietySummary` 内の冗長な `setupSheets` 再呼び出しを削除（呼び出し元の `saveAggregatedData` で実行済み）。

3. **マスター定義の整理（`gas_app/js/config.js`）**
   - `OPERATION_MODES` を削除。
   - `EQUIPMENT_COLUMNS[].category`（90件）を削除。実際の集計に使う `CATEGORY_COLUMN_MAP` と17列で食い違っており、参照も無かった。

4. **ETL・サービスの読まれないフィールドの削除**
   - `gas_app/js/etl/csvParser.js`: tag02 の「運転」列の取り込み（`rec.operation`）。
   - `gas_app/js/etl/hourlyAggregator.js`: `rowNumber` / `validMinuteCount` / `stepCode`、CIP / SIP / その他の分数カウント。
   - `gas_app/js/services/categoryService.js`: CIP / SIP / その他の分数の日別・月別集計、戻り値の `categoryHourlyRows`。
   - `gas_app/js/services/annualService.js`: `OPERATION_MODES` の取り込み。
   - `gas_app/js/services/kpiService.js`: 使っていない `AppConfig` の取り込み。

5. **フロントエンドの未使用箇所の削除（`gas_app/js/app.js`、`gas_app/js/components/charts.js`）**
   - 年間月別実績集計表の到達しない累計原単位の算出分岐と専用変数を削除。データのある月には必ず数値の累計値が入るため、この分岐は実行されていなかった。
   - 存在しない `AppConfig.VARIETY_KEYS` へのフォールバックを削除。
   - 書き込みだけの状態・変数（`detectedTags`、`currentCategoryResult`、`currentKpiResult`、`externalData.production`、`fixedScaleInputsArea`）を削除。
   - デバッグ用の `console.log`、重複していたセクション見出しコメントを削除。
   - `VARIETY_COLORS['月計']`、渡す側の無い `scaleOptions.trendMax` を削除。

6. **未使用スタイルの削除（`gas_app/css/style.css`）**
   - `.chart-grid.single`、未使用のCSS変数（`--secondary-hover`、`--warning-light`、`--danger-light`、`--color-*`、`--border-focus`）を削除。

7. **本番成果物の再生成（`gas_app/index.html`）**
   - `node gas_app/build.js` を実行。
