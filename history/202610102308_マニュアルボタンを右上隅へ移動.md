# 作業履歴: マニュアルボタンを右上隅へ移動

## 実施日時
2026-10-10 23:08

## 修正理由・背景
- ユーザーより、「マニュアル画面へのリンクボタンは、目盛り設定など機能ボタンと同列で並ばずに、右上隅に配置してほしい」との依頼を受けた。
- それまで「マニュアル」ボタンは、ヘッダーのボタン群（反映状況の表示、目盛り設定、Excelエクスポート、スプレッドシートへ反映）の中に、同じ列で並んでいた。

## 修正内容

ヘッダーのカードを2段に分け、「マニュアル」ボタンを上段の右端（カードの右上隅）に置いた。

```
┌──────────────────────────────────────────────────────────┐
│ ⚡ 工場エネルギー使用量集計・分析システム      [📖 マニュアル ↗] │
│    月別電力使用量集約グラフ…                                  │
│ ● 読込済: 計12ヶ月…  [⚙ 目盛り設定] [Excelエクスポート] [☁ 反映] │
└──────────────────────────────────────────────────────────┘
```

1. **`gas_app/index.template.html`**: 「マニュアル」ボタンをボタン群（`.header-actions`）の外へ出し、タイトル（`.header-logo`）の直後に移した。ボタンの ID・中身は変えていない。
2. **`gas_app/css/style.css`**:
   - `.manual-link-btn` に `margin-left: auto` を追加（タイトルと同じ段の右端へ寄せる）。
   - `.header-actions` に `flex: 1 1 100%` を追加（反映状況と機能ボタンを、常にタイトルの下の段へ送る）。
3. **`tools/capture_manual_screenshots.js`**: 図1-1 の注釈番号を、新しい並びに合わせて振り直した（タイトル ❶ → マニュアル ❷ → 反映状況 ❸ → …）。
4. **`gas_app/manual.template.html`**: 1章の番号と説明の対応表を、新しい番号順に並べ替えた（「マニュアル」が ❸ から ❷、反映状況が ❷ から ❸）。「マニュアル」の説明に「画面の右上にあります」を追記。
5. **`gas_app/manual_images/`**: 図 11 枚を撮り直した（ヘッダーが写る図1-1・図7-1 の見た目が変わるため）。
6. **`gas_app/index.html`、`gas_app/manual.html`**: 再生成。
7. **`docs/02_システム設計.md`**: ヘッダーの説明を、2段の構成とボタンの位置に合わせて更新。
8. **`docs/05_セットアップ手順.md`**: 「画面右上の『スプレッドシートへ反映』ボタン」という記述（3か所）を「ヘッダーの…」に修正（反映ボタンは下段にあるため）。マニュアルボタンの案内を「ヘッダー右上の…」に修正。

`app.js`・`Code.gs` は変更していない。

## 検証結果

### ヘッダーの配置（40 項目すべて OK）
画面幅 1600・1240・900・600px、データ未読込／読込後、本番と同じ見た目（開発用のデモボタンなし）／ローカル（デモボタンあり）の組み合わせで、ヘッダーの各要素の位置を測って確認した。

| 画面幅 | 「マニュアル」ボタン | 機能ボタン |
|---|---|---|
| 1600・1240・900px | タイトルと同じ段の右端（カードの右上隅） | すべて「マニュアル」より下の段 |
| 600px | タイトルの下の段の右端（タイトルと1段に収まらないため） | すべて「マニュアル」より下の段 |

- タイトルとボタンは重ならず、ヘッダーは画面からはみ出さない。
- 電力・燃料エネルギー・トータルエネルギーのどの画面でも、ボタンの位置は同じ。

### 既存画面への影響
- 変更前後を同じ手順で操作し（34 ステップ）、電力の3ビュー・燃料エネルギー・トータルエネルギーの各ビューの HTML、グラフ、表、反映状況、通知が変わらないことを確認した。
- 機能ボタン群（`.header-actions`）の HTML は、マニュアルを追加する前（コミット済みの状態）と完全に同じになった。

### マニュアルとボタン
- マニュアルの紙面の確認 22 項目（図の中の番号と本文の番号の一致、画面上の文言 61 種類の照合、目次のリンク、印刷用・狭い画面の表示など）がすべて OK。
- ボタンの動作と `Code.gs` の振り分けの確認 16 項目がすべて OK（3画面のどれからでも開ける、GAS を模した環境で `?page=manual` 付きのURLを開く、など）。
- 既存のテスト一式がすべて成功。

## 未確認事項・注意点
- **GAS 環境では未確認。** 反映には、`index.html` と `manual.html` の貼り替えと再デプロイが必要（操作マニュアルをまだ GAS に置いていない場合は、`manual` の新規作成と `Code.gs` の貼り替えも必要）。
- **ヘッダーが常に2段になった。** これまでは、データ未読込で画面幅が広いときだけ、タイトルとボタン群が1段に収まっていた。データを読み込んだ後は以前から2段のため、普段の見た目は変わらない。
- 画面幅が 600px 程度まで狭い場合は、「マニュアル」ボタンがタイトルの下の段の右端に回る（タイトルと1段に収まらないため）。
- 確認の過程で、**ウィンドウの幅を途中で狭めると、グラフのカードが元の幅のまま残り、画面が横にはみ出す**ことに気付いた。変更前のビルドでも同じ値で起きており、今回の変更とは無関係（既存の挙動）。最初からその幅で開いた場合（マニュアルの図を撮影した幅 1240px）は、表示は崩れていない。今回は対応していない。
