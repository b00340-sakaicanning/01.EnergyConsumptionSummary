# 作業履歴: 202610050410_品種コード原紙完全一致_操業モード分離_反映済み除外実装

## 1. 概要
- **ユーザー確認・依頼事項**:
  1. 2024年度のデータを反映後、続けて2025年度のデータ（CSV・Excel）を選択しようとしても読込が有効にならず読み込めない。
  2. 2024年度において、280mlの生産本数、280mlと600mlの操業時間・電力量がおかしい。
  3. 「水運転＋実充填」と「実充填のみ（実運転だけ）」の数値が同じになっている。
  4. 集約データ行数が読み込み直後は表示されているが、一度ブラウザを閉じて再表示すると「---」表示になる。
  5. 【依頼事項】スプレッドシート反映済みの月は再反映処理の対象から除外し、画面に「読込済: 計Xヶ月 (未反映: Yヶ月 / 反映済: Zヶ月)」のステータスを表示してほしい。

## 2. 原因と改修内容

### ① 追加ファイル読込の不具合解消
- **原因**: `<input type="file" id="fileInput">` の `change` イベント後に `value = ''` が行われておらず、ブラウザが値変更なしと判定してイベントが不発になっていた。
- **改修**: `fileInput` の change イベント時および `handleFiles` 完了時に `fileInput.value = ''` を確実に実行し、連続選択・フォルダ選択を常に有効化。

### ② 原紙Excel「品種」シートに基づく品種コード完全一致修正
- **原因**:
  - 原紙Excel（`月別電力使用量集約(31日版原紙).xlsx`「品種」シート）の定義:
    - 105: 600ml 丸
    - 106: 525ml 丸（500ml丸グループ）
    - 107: 500ml 丸（500ml丸グループ）
    - 108: 500ml 角（500ml角グループ）
    - 109: 350ml 角（350mlグループ）
    - 110: 280ml 丸（280mlグループ）
  - 従来のプログラムでは 107 を「280ml 丸」、105 を「500ml 丸」、108 を「2L 6角」、109 を「500ml 6角」と誤認していたため、500ml丸のデータが280mlに集計され、月報PETの按分フォールバックで280mlに本数・電力量が自動配分されていた。
- **改修**:
  - `gas_app/js/config.js` の `VARIETY_MASTER` および `VARIETY_GROUPS` を原紙Excelに完全合致。
  - `annualService.js` で月報PETにデータがある場合、0本指定の品種に勝手に操業時間から本数が付与されないようガードを追加。

### ③ 操業モード（水運転＋実充填／実充填のみ／水運転のみ）の分離保存・完全復元
- **原因**: スプレッドシートの「品種別集約」シートに `combined`（合算）のみ保存しており、復元時に `fillingOnly` にも合算値を代入していた。
- **改修**:
  - `Code.gs`: 「品種別集約」シートを 41列形式（本数×8、実充填kWh×8、水運転kWh×8、実充填分×8、水運転分×8）へ拡張。
  - `loadSavedSummaryFromSpreadsheet`: 実充填と水運転を個別に取得し、`combined`（合算）、`waterOnly`（水運転のみ）、`fillingOnly`（実充填のみ）の3操業モードを完全分離復元。
  - `app.js`: `handleSyncToSpreadsheet` で各操業モードの数値をスプレッドシートへ送信。

### ④ 集約データ行数のフォールバック表示
- **原因**: スプレッドシート復元データには生の 1時間集約行配列（`aggResult.rows`）がないため `---` になっていた。
- **改修**: `aggResult.rows` がない場合でも、復元された `categoryDailyTotals` の日数 × 24時間（例: 31日なら 744時間分）を自動算出して「744」のように確実に表示。

### ⑤ スプレッドシート反映済み除外＆ステータス表示の実装
- **改修**:
  - `state.syncedYms`（反映済み年月Set）を導入。
  - 起動時復元月および送信完了月を「反映済み」として管理。
  - ヘッダーにステータスバッジ（`syncStatusBadge`）を追加し、「読込済: 計 X ヶ月（未反映: Y ヶ月 / 反映済: Z ヶ月）」を視覚的に表示。
  - 「スプレッドシートへ反映」ボタンは**未反映月のみ**を送信対象とし、重複送信を防止。全月反映済みの場合は確認ダイアログを表示。
  - ボタンラベルも `☁️ スプレッドシートへ反映 (未反映 Yヶ月分)` のように未反映件数を動的に表示。
