# 作業履歴: 202610050420_1時間集計シートヘッダー位置修正

## 1. 概要
- **ユーザー確認・依頼事項**:
  - 1時間集計(ALL)シートのヘッダー位置が9行目になっているため、2行目から読み書き（データ配置）されるように修正してほしい。

## 2. 原因と改修内容

### ① 「1時間集計(ALL)」のヘッダー行および固定行設定の修正
- **原因**:
  - 原紙Excel（`月別電力使用量集約(31日版原紙).xlsx`）のレイアウト（1〜8行目がメタ情報、9行目にタグID、10行目に実データ）をそのまま模して `setupSheets` で行9にヘッダーを書き込み、`setFrozenRows(9)` としていた。
- **改修**:
  - `gas_app/Code.gs` の `setupSheets`:
    - ヘッダー配置行を `9行目` → **`1行目`** (`sHourly.getRange(1, 1, 1, header.length)`) に変更。
    - ウィンドウ固定行を `9行` → **`1行`** (`sHourly.setFrozenRows(1)`) に変更。
    - 既存シートが存在する場合でも、1行目が空欄であれば自動的に1行目へヘッダーを書き込み固定行を1行に調整する安全ガードを追加。

### ② 既存データ走査・追記開始行の修正
- **原因**:
  - `saveAggregatedData` において、データ探索の開始行と追記最小行が `10行目` 起点（`lastRow >= 10`, `sheetHourly.getRange(10, 1, lastRow - 9, 1)`, `targetRow = Math.max(lastRow + 1, 10)`) となっていた。
- **改修**:
  - `gas_app/Code.gs` の `saveAggregatedData`:
    - 既存データ走査判定を `lastRow >= 2`、走査範囲を `sheetHourly.getRange(2, 1, lastRow - 1, 1)`、一致行を `r + 2` に変更。
    - 新規データ追記行を `Math.max(lastRow + 1, 2)` に変更（ヘッダー1行目の直下である2行目から追記）。
