# 作業履歴: 燃料エネルギー画面の追加

## 実施日時
2026-10-08 23:18

## 修正理由・背景
- ユーザーより、「現在のアプリは `reference` フォルダの『月別電力使用量集約グラフ表示』Excel の内容を実現している。『月別燃料エネルギー使用量集約グラフ表示』Excel の内容も同様にアプリ化し、画面上のボタンまたはタブで切り替えられるようにしてほしい。読み込むデータはエネルギー計算表と月報データのみになるはずだが、確認してほしい」との依頼を受けた。
- 参考 Excel（`reference/参考用データ/月別燃料エネルギー使用量集約グラフ表示(2024).xlsx`）を調べた結果:
  - 燃料は A重油と LNG の2種で、合算した熱量（MJ）と費用（円）を、品種ごとの液量（本数 × 容量）の比で8品種に按分している。
  - 使うデータは、エネルギー計算表の4行（A重油・LNG それぞれの `熱量GJ` と `購入費用（千円）`）と、月報PETの品種別の充填本数。
  - **ただし、操業時間と、それを分母にする2項目（単位時間あたりの燃料エネルギー・コスト）は、Excel 2種だけでは再現できない。** ロガーデータ由来の品種別の操業時間が必要で、これは電力側が集計・保存している値である。

ユーザーに確認した方針:
- 切り替えは、ヘッダーの下に置く上位の切替ボタン（電力／燃料エネルギー）。
- 操業時間は、電力側の既存データ（読込済み、またはスプレッドシートから復元した値）を使う。無い月は、操業時間系の3項目だけ「---」と表示する。
- 単位時間あたりの項目は、電力の画面に合わせて1分あたり（MJ/分、円/分）。
- 燃料のデータもスプレッドシートに保存する（反映・起動時の復元・エクスポート）。

## 検証結果

### 参考 Excel との突合（2024年度）
- 読込用の実ファイルから計算した値を、参考 Excel の `実績値` と比べた（8項目 × 12か月 × 8品種と、月計・累計・年間計。単位時間の項目は参考 Excel の値 ÷ 60）。
- 参考 Excel と読込用ファイルの入力が食い違う3か所を参考 Excel の値に置き換えると、**比較した 1,032 項目すべてが一致**した。
- 置き換えない場合の差は、その3か所に由来する月だけだった。

| 食い違う箇所 | 参考 Excel | 読込用ファイル |
|---|---:|---:|
| 2024年4月 LNG 熱量(GJ) | 5,045.528 | 5,196.5 |
| 2024年12月 LNG 購入費用(千円) | 10,224.66 | 9,572.05 |
| 2024年12月 2.0L 本数 | 1,032,260 | 1,033,260 |

- 操業時間（電力側がロガーデータから集計した値）は、参考 Excel と月計で 0〜1.1% 違う。品種別では 96 件中 22 件が一致し、残りは数分〜数十分の差。電力側が1時間ごとに主な品種へ割り当てているためで、電力側の既存の挙動（今回は変更していない）。

## 未確認事項・注意点
- **GAS 環境では未確認。** `Code.gs`・`Config.gs`・`index.html` の3ファイルを貼り替えて再デプロイしたうえで、次の確認が必要。
  - 燃料エネルギー: `燃料集約` シートの作成、反映（138 か月をまとめて保存）、再読み込み後の復元と「反映済み」の表示、エクスポート（4シート）。
  - 電力: 起動時の復元、反映、エクスポートが従来どおり動くこと。
  - 模擬環境では、スプレッドシートが数値に見える文字列を数値に変換する挙動までは再現しているが、実際のスプレッドシートでの値の丸めや書き込み時間は確認できていない。
- 参考 Excel と一致しない月がある（上記の3か所の入力差による）。アプリの値は読込用ファイルに基づく。
- 費用は購入した月に計上される値、熱量は使用した月の値のため、月ごとの燃料単価（円/MJ）は大きく変わる（購入の無い月は A重油の費用が 0）。参考 Excel と同じ挙動で、そのまま再現している。
- 月の生産本数は、8品種の充填本数の合計（参考 Excel と同じ）。電力側の生産本数（月報PETの `実績（本)`）とは少し違うことがある（例: 2024年4月は 9,919,599 と 9,902,380）。
- 品種のまとめ方は電力側と同じ。`550ml丸` は `500mL丸` に合算され、容量 0.5L として按分する。`900ml` はどの品種にも入らない。
- 操業時間が極端に短い品種・月では、単位時間あたりの値が極端に大きくなる。また、月報PETに本数があるのに、電力側の集計で操業時間が 0 分になる品種・月があり、その場合は単位時間あたりの値を 0 と表示する（例: 2025年1月の 1.0L。参考 Excel では操業時間が 18 分で、極端に大きな値になっている。電力側の集計では 0 分）。
- 2026年度の月報PETは、充填本数が5月までしか入力されていない。6月以降は、既存の仕様どおり `入数 × 実績(C/S)` で代替した本数になる。
- エネルギー計算表にあるすべての年度（2013年度〜）が読み込まれ、反映するとすべて `燃料集約` シートへ保存される。
- 燃料エネルギーの画面で Excel を投入するたびに、対象外の年度（2016〜2017年度）と月報PETにシートが無い年度の警告が毎回表示される。
- 新しい `Code.gs` では、電力のデータを反映したときにも、空の `燃料集約` シート（ヘッダーのみ）が作られる。その状態でエクスポートすると、ヘッダーだけの `燃料集約` シートが出力に含まれる。
