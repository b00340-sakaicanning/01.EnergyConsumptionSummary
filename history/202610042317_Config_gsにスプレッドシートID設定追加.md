# Config.gsへのスプレッドシートID設定追加およびGASスプレッドシート参照の対応

## 作業日時
2026-10-04 23:17

## 概要
セットアップ手順書（`docs/05_セットアップ手順.md`）の記載に基づき、`gas_app/Config.gs` にスプレッドシートID（`SPREADSHEET_ID`）の設定項目を追加し、`gas_app/Code.gs` において指定されたIDのスプレッドシートを開く機能（スタンドアロンスクリプト対応およびコンテナバインドスクリプト自動認識対応）を実装しました。

あわせて、フロントエンド側で追加された新設備区分（ユーティリティ、コンプレッサー、ボイラー、純水装置、排水処理）を GAS側の `CATEGORIES` マスター定義にも同期反映しました。

---

## 実施内容

### 1. Config.gsの修正 ([gas_app/Config.gs](file:///Users/shitimi/Documents/02.作業用/01.pgwork/01.antigravity/01.gemini/01.エネルギー使用量集計/gas_app/Config.gs))
- `CONFIG` オブジェクトの先頭に `SPREADSHEET_ID: ''` を追加。
  - コンテナバインドスクリプト時は空文字 `''` で自動認識。
  - スタンドアロンスクリプト時は対象スプレッドシートのIDを指定可能。
- `CATEGORIES` に `utility`, `compressor`, `boiler`, `pureWater`, `drainWater` を追加し、フロントエンドの定義と同期。

### 2. Code.gsの修正 ([gas_app/Code.gs](file:///Users/shitimi/Documents/02.作業用/01.pgwork/01.antigravity/01.gemini/01.エネルギー使用量集計/gas_app/Code.gs))
- スプレッドシート取得用関数 `getSpreadsheet()` を新設：
  ```javascript
  function getSpreadsheet() {
    if (CONFIG.SPREADSHEET_ID && String(CONFIG.SPREADSHEET_ID).trim() !== '') {
      return SpreadsheetApp.openById(String(CONFIG.SPREADSHEET_ID).trim());
    }
    return SpreadsheetApp.getActiveSpreadsheet();
  }
  ```
- `saveAggregatedData` および `setupSheets` で `getSpreadsheet()` を呼び出すよう修正。
