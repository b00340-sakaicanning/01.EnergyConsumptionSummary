# 01. 要件定義書 - 工場エネルギー（電力・燃料・トータルエネルギー）使用量集計システム

## 1. システム概要
本システムは、工場の各設備・電源盤から1分間隔で出力される電力ロガーCSV/テキストデータをブラウザ上で自動判別・パース・集約し、60分平均による1時間電力量（kWh）および日別・月別・年別集計、さらに生産実績情報（月報PET）および電気料金計算表（エネルギー計算表）と連携した「原単位（kWh/本、円/本）」の自動算出と可視化を行うシステムである。

あわせて、燃料（A重油・LNG）についても、エネルギー計算表の熱量・購入費用と月報PETの品種別本数から、品種別の燃料エネルギー（MJ）・コスト・原単位（MJ/本、円/本など）を算出して可視化する。さらに、エネルギー計算表にある工場全体の生産量・エネルギー使用量（原油換算）・熱量・原単位・CO2排出量を「トータルエネルギー」として可視化する。電力・燃料エネルギー・トータルエネルギーは、画面上部の切替ボタンで切り替える。

現場担当者がPython等のローカル環境構築を行うことなく、Webブラウザ（Google Apps Script Web App）上にファイルをドラッグ＆ドロップするだけで、数秒〜数十秒で全処理が完了する「ゼロ環境構築・ブラウザ完結型」の構成とする。

---

## 2. 目的・背景
- **現状の課題**:
  - 毎月、複数の電源盤ロガーから出力される膨大な1分値データ（1ファイル約4.5万行×5系統＝約22万行以上）を手作業でExcel等にコピー＆ペーストし、AVERAGE関数で1時間値に丸めて集約していた。
  - 停電や通信瞬断等によるデータの欠損、月末の締めタイミングの違い（23:59終了など）に対する補正を手作業で判断しており、集計に多大な工数と計算ミスのリスクが存在した。
  - 生産実績や電気代との紐付けが手動計算となっており、省エネ改善やコスト分析のための原単位のタイムリーな把握が困難であった。
- **導入の目的**:
  - ファイルのドラッグ＆ドロップのみで、全90系統の電力データを自動で1時間単位に平均化集約する。
  - Excel原紙（過去実績値）と100.00%数値突合が一致する高精度な2段階欠損補正ロジックを自動適用する。
  - Googleスプレッドシートへの蓄積およびExcelエクスポートを容易にし、社内共有と分析を迅速化する。

## 3. 機能要件

### 3.1 データ取り込み・パース機能
- **複数系統ファイルの自動判別**:
  - ファイル名およびヘッダー情報から、測定対象タグ（tag02, tag04, tag05, tag06, tag07）および外部データ（月報PET、エネルギー計算表）を自動判別。
- **日別生CSVおよびフォルダ一括ドロップ対応**:
  - 月次結合CSVだけでなく、ロガーから出力される日別ファイル群（`AQYYYYMMDD_*.TXT`）やフォルダ全体のドロップに対応し、ブラウザ上で全自動グループ化・日付マージを実行。
- **センサー異常値・外れ値自動補正機能**:
  - 工場ロガー特有のエラーコード（`21,000,000` や `210,000,000` などのオーバーレンジ）や物理的上限制限（`1,000 kW` 超過）、直前値からの急激な異常スパイク（`500 kW` 超差分）を検知し、直前有効値により自動補正して集計歪みを防止。
- **不要列のフィルタリング**:
  - 電流（A）や電圧、無効電力などの不要データを除外し、有効電力（kW）列および品種・工程ステップ列のみを正確に抽出。
- **複数月・年次一括処理**:
  - 単月分のみならず、過去数ヶ月分や年間のファイルを一括で投入した場合でも、年月（YYYYMM）ごとに自動グループ化して連続処理可能。

### 3.2 1時間集約・欠損補正機能
- **01分締め（XX:01〜(XX+1):00）集約**:
  - ロガー仕様に準拠し、毎時01分から翌時00分までの60サンプルを1時間区間として集約。
- **高精度2段階欠損補正**:
  - **1時間以内の欠損（短時間欠損）**: 同一時間枠内の有効サンプルによる平均値（`ROUND(AVERAGE, 1)`）を採用。
  - **1時間以上の連続欠損（長時間停電等）**: 直前の有効な時間帯の値をそのまま引き継いで補完し、補間フラグを立てる。月初などで直前の値が無い場合は 0 とする。
  - **月末23:59パディング**: 月末最終データが23:59で終了している場合、最終値を24:00として自動補間。

### 3.3 カテゴリ集計・KPI算出機能
- **11カテゴリ小計の自動集計**:
  - 総電力、ユーティリティ（およびその内訳であるコンプレッサー、ボイラー、純水装置、排水処理、チラー）、調合抽出、供給、充填、包装の各カテゴリごとに日別・月間小計を自動算出。
- **操業時間集約**:
  - tag02のステップ大分類に基づき、「水運転時間（コード20）」および「実充填時間（コード30）」の月間合計分・時間を自動集計。
- **操業3モード原単位・コスト分析**:
  - パターンA（水運転＋実充填）、パターンB（水運転のみ）、パターンC（実充填のみ）の各モードにおける単位時間電力量（kWh/分）、原単位（kWh/本）およびコスト原単位（円/本）を自動算出。

### 3.4 年間推移・品種別・設備別集計機能 (月別電力使用量集約グラフ表示(総電力 2024).xlsx 準拠)
- **品種8大分類集計**:
  - ロガーデータ（tag02）より、`2.0L`, `1.5L`, `1.0L`, `600mL丸`, `500mL丸`, `500mL角`, `350mL`, `280mL` の8分類での電力量・操業時間・原単位の自動集約。
- **年間12ヶ月（4月〜翌3月）月別集計**:
  - 4月〜3月の各月実績値および年間計・期中累計の算出。
  - 8大評価項目（電力量、操業時間、生産本数、原単位、単位時間電力量、コスト、単位本コスト、単位時間コスト）の動的切り替え表示。
- **年間推移グラフ**:
  - 月別電力使用量集約グラフ。総量系の指標（電力量、操業時間、生産本数、電力コスト）は8品種の積み上げバー、原単位系の指標（単位本・単位時間の電力量とコスト）は8品種の集合バー＋全体平均の折れ線で表示。
  - 8品種の年間トレンド推移折れ線グラフ。
- **設備別年間推移・分析機能**:
  - 工程・設備カテゴリ（ユーティリティとその内訳、調合抽出、供給、充填、包装）ごとの月別電力量推移および年間累計比率の集計・グラフ化。

### 3.5 画面表示・可視化機能
画面上部の切替ボタンで「電力」「燃料エネルギー」「トータルエネルギー」を切り替える。電力は「年間推移・品種別分析」「年間推移・設備別分析」「単月詳細集約」の3ビュー構成、燃料エネルギーとトータルエネルギーはそれぞれ1ビュー構成とする（表示内容は 3.7、3.8）。以下は電力の画面の内容。
- **KPIサマリーカード**:
  - 年間・品種別: 年間総電力量、年間操業時間、年間総生産本数、年間平均原単位。
  - 年間・設備別: 年間総電力量、年間ユーティリティ電力量、最大電力消費設備、年間実充填操業時間、年間水運転時間。
  - 単月詳細: 月間総電力量、実充填操業時間、水運転時間、電力量単価、集約データ行数。
- **インタラクティブグラフ**:
  - 年間月別電力使用量集約グラフ（8品種バー）。
  - 年間月別電力推移折れ線グラフ（8品種）。
  - 月別設備別・工程別電力推移グラフ（総電力の折れ線＋積み上げバー。ユーティリティ統合／設備詳細内訳の切り替え）。
  - 日別電力使用量推移（総電力の折れ線＋工程別の積み上げバー）。
  - 工程別電力比率ドーナツチャート（内側: 工程大分類、外側: ユーティリティ内訳の多層構造）。単月・年間の両方。
- **データテーブル**:
  - 年間月別実績集計表（4月〜3月＋年間計、累計・月計・8品種）。
  - 年間推移・設備別集計データ表（設備・工程区分ごとの年間累計、構成比、月別値）。
  - 日別工程別集計データ（日付、工程別電力、操業時間）。
- **年月・年度セレクター**:
  - 年間ダッシュボードの年度切り替え（2024年度、2025年度等）。
  - 単月詳細分析の年月切り替え（過去月へのオンデマンド切り替え）。
- **目盛り設定**:
  - グラフの縦軸上限を「自動」または「固定値」から選択し、ブラウザ（localStorage）に保存。

### 3.6 外部連携・出力機能
- **スプレッドシート同期（Upsert & 復元）**:
  - `1時間集計(ALL)`、`日別集約`、`KPI評価`、`品種別集約` の4シートへ日時キー・年月キーで差分更新・追記。
  - アプリ起動時に、`日別集約`・`KPI評価`・`品種別集約` の保存済みデータを自動読み込みして画面を復元（`1時間集計(ALL)` は蓄積専用で、復元には使わない）。
  - 燃料エネルギーのデータは `燃料集約` シートへ、トータルエネルギーのデータは `トータルエネルギー集約` シートへ、それぞれ月1行で保存し、起動時に復元する（3.7、3.8）。
- **Excelエクスポート**:
  - スプレッドシート上の `日別集約`・`KPI評価`・`品種別集約`・`燃料集約`・`トータルエネルギー集約` の5シートを、そのままExcel（.xlsx）としてワンクリックでダウンロード。スプレッドシートへ未反映のデータは含まれない。データの無いシートは出力されない。

### 3.7 燃料エネルギー集計機能 (月別燃料エネルギー使用量集約グラフ表示(2024).xlsx 準拠)
- **対象の燃料**: A重油と LNG。2つを合算した熱量（MJ）と費用（円）で表示する。
- **入力データ**:
  - エネルギー計算表: A重油・LNG それぞれの月別の `熱量GJ` と `購入費用（千円）`。
  - 月報PET: 8品種別の月別の充填本数。
  - 品種別の操業時間（水運転＋実充填）: 電力の画面で読み込んだロガーデータ、またはスプレッドシートに保存済みの電力のデータから取得する。Excel 2種だけでは得られない。
  - Excel は電力の画面と同じファイルを共用する。どちらの画面から投入しても、両方に反映する。
- **表示する年度**: 月報PETに年度のシートがある年度だけを表示・保存する（3.9）。
- **品種別への按分**: 月の燃料エネルギーを、品種ごとの液量（本数 × 1本あたりの容量）の比で8品種に按分する。
- **8評価項目**: 燃料エネルギー（MJ）、操業時間（分）、生産本数（本）、単位本燃料エネルギー（MJ/本）、単位時間燃料エネルギー（MJ/分）、燃料エネルギーコスト（円）、単位本コスト（円/本）、単位時間コスト（円/分）。操業モードの切り替えは無い（水運転＋実充填のみ）。
- **表示内容**:
  - KPIカード: 年間燃料エネルギー、年間燃料コスト（平均単価）、年間総生産本数、年間平均原単位。
  - 月別燃料エネルギー使用量集約グラフ（総量系は8品種の積み上げバー、原単位系は8品種の集合バー＋全体平均の折れ線）と、品種別の推移（折れ線）。
  - 年間月別実績集計表（年月、累計、月計、8品種）。
  - 燃料別の熱量・費用の表（A重油・LNG の熱量と購入費用、合計、燃料単価）。
- **値が無い場合の表示**:
  - 表示する年度の中で品種別の本数が無い月（月報PETで未入力の月）は、月計だけを表示し、品種別の値と本数あたりの指標は「---」とする。
  - 操業時間が無い月は、操業時間・単位時間燃料エネルギー・単位時間コストの3項目だけを「---」とする。
- **保存**: 月ごとの入力値（燃料の4値と品種別本数）を `燃料集約` シートへ保存し、起動時に復元する。反映の対象は、未反映の月と、保存後に値が変わった月。

### 3.8 トータルエネルギー集計機能 (かつらぎ工場エネルギー計算表の年度シート 準拠)
エネルギー計算表の各年度シートの上部にある4つのグラフ（生産量＆エネルギー使用量推移、熱量推移、原単位推移、CO2排出量推移）と年間サマリーに相当する内容を表示する。

- **入力データ**: エネルギー計算表の年度シート。月別の生産数量（ケース）、A重油・LNG・電気の熱量（GJ）と CO2排出量（t-CO2）、それらの合計、原油換算量（kl）、太陽光発電の発電量・熱量・CO2。熱量・CO2・原油換算の係数は年度によって違うため、Excel が計算した値をそのまま使う（アプリでは再計算しない）。
- **表示する年度**: 月報PETに年度のシートがある年度だけを表示・保存する（3.9）。値そのものはエネルギー計算表だけで決まり、月報PETは表示する年度を決めるためだけに使う。
- **表示の切替**: 「月別」（対象年度の4月〜3月）と「年度推移」（各年度の年間値を並べたもの）。入力途中の年度は、年度推移で月数を添えて表示する。
- **アプリで計算する値**:
  - 原単位（kl/千ケース）= 原油換算量 ÷ 千ケース
  - 生産液量1klあたりのCO2排出量（kg-CO2/kl）= CO2排出量 × 1000 ÷ 生産液量（ケース × 1ケースあたりの容量 ÷ 1000）
  - 生産数(千ケース)あたりのCO2排出量（t-CO2/千ケース）
  - 累計・年間計（原単位などの比は、合計どうしの比）、前年度比
- **表示内容**:
  - KPIカード（対象年度）: 年間生産量、エネルギー使用量（原油換算kl、熱量GJ）、原単位、CO2排出量（生産液量1klあたり）。それぞれ前年度比を添える。
  - グラフ4つ: 生産量＆エネルギー使用量推移（2軸の折れ線）、熱量推移（A重油・LNG・電気の積み上げ棒）、原単位推移（折れ線）、CO2排出量推移（排出量の内訳の積み上げ棒＋生産液量1klあたりの折れ線）。
  - 集計表: 生産数量、A重油・LNG・電気・合計の熱量、原油換算量、原単位、累計の原単位（年度推移では原単位の前年度比）、CO2排出量、1klあたり・千ケースあたりの CO2。月別では最下行に年間計。
  - 参考表「太陽光発電 無しの想定値」: 太陽光の発電量・熱量と、太陽光分を合計に足し戻した場合の熱量・原油換算量・原単位・CO2。太陽光のデータがある年度だけ表示する。
- **前年度比**: 前年度も表示する年度に含まれる場合に表示する。原単位と1klあたりの CO2 は常に、総量（生産量・エネルギー使用量）は当年度・前年度とも12か月そろっている場合だけ表示する。
- **保存**: Excel から読んだ月ごとの値を `トータルエネルギー集約` シートへ保存し、起動時に復元する。反映の対象は、未反映の月と、保存後に値が変わった月。
- **対象外**: 近似式による将来予測（`年度推移_予測用` シート）、`必要削減率` シート、エネルギーコスト（円/ケース）。

### 3.9 燃料エネルギー・トータルエネルギーで表示する年度
- 読み込んだ月報PETに年度のシート（シート名に年度の数字を含むシート）がある年度だけを、表示・保存の対象にする。エネルギー計算表には古い年度のシートもあるが、月報PETにシートが無い年度は表示しない。
- 月報PETを読み込んでいない場合は、スプレッドシートから復元したデータの年度を対象にする（燃料エネルギーは品種別本数が保存されている年度、トータルエネルギーは保存されている年度）。
- エネルギー計算表だけを読み込み、月報PETも復元データも無い場合は、月報PETの投入を案内する。

## 4. 非機能要件
- **操作性・アクセシビリティ**:
  - 専門知識やPython等のインストール不要。Chrome等のモダンブラウザがあれば誰でも即日運用可能。
- **パフォーマンス**:
  - 月間約22万行（1分値×5タグ）のパース・集計・描画をブラウザ側JavaScriptで高速実行（平均処理時間 2秒以内）。
  - GASの実行時間制限（6分）を回避するため、ブラウザ側で1時間値（744行）に圧縮してからGASへ送信。
- **データ整合性・信頼性**:
  - リファレンスExcel原紙（2025年3月度 66,960データポイント）との数値突合において100.00%完全一致を保証。
