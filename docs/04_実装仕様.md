# 04. 実装仕様書 - 工場エネルギー（電力）使用量集計システム

## 1. コア計算ロジック仕様

### 1.1 01分締め（XX:01〜(XX+1):00）集約ロジック
工場の電力ロガー仕様に基づき、各時間帯の集計枠は **毎時01分から翌時00分までの60分間** とする。

```
【例: 2025/03/01 01:00 の集計対象範囲】
開始: 2025/03/01 00:01:00
終了: 2025/03/01 01:00:00
サンプル数: 最大60件
```

- **時間帯インデックス計算式**:
  ```javascript
  // mm: 01〜59 の場合 => そのままの時 (例: 00:15 => Hour 0)
  // mm: 00 の場合 => 直前の時 (例: 01:00 => Hour 0)
  const targetHour = (minute === 0) ? hour - 1 : hour;
  ```

### 1.2 高精度2段階欠損補正ロジック

Excel原紙との完全一致（100.00%突合）を達成するための欠損値処理アルゴリズム。

#### (1) 短時間欠損（1時間枠内での部分欠損）
- 1時間枠内（最大60サンプル）のうち、有効な測定値が存在する場合：
  $$\text{HourlyValue} = \text{ROUND}\left(\frac{\sum_{i=1}^{N} \text{Sample}_i}{N}, 1\right)$$
  - $N$: 当該時間枠内の有効サンプル数（$1 \le N \le 60$）
  - 丸め処理: 小数第1位で四捨五入（Excelの `ROUND(AVERAGE(...), 1)` と完全一致）

#### (2) 長時間欠損（1時間以上の連続欠損・停電）
- 1時間枠内のサンプル数が 0 の場合：
  - 前後の有効時間帯の値を用いた線形補間、または設備電源OFF時のベース値（0.0）を適用。

#### (3) 月末23:59パディング補正
- ロガーデータが月末最終日の `23:59:00` で終了している場合、Excel原紙の仕様に基づき、`23:59:00` の値を `24:00:00`（翌月00:00:00）としてパディング複製し、最終時間枠（23:01〜24:00）を正常に集約する。

### 1.3 センサー異常値・外れ値自動補正ロジック
工場ロガーの通信途絶、センサー断線、オーバーレンジによる極端な異常値（例: 排水処理盤で記録された `21,000,000 kW` や `210,000,000 kW`）による集計値破壊を防止するためのリアルタイム補正アルゴリズム。

- **判定基準**:
  1. **絶対上限値超過**: $\text{val} \ge 1,000\text{ kW}$
  2. **急激な異常スパイク**: $|\text{val} - \text{lastValidValue}| > 500\text{ kW}$（直前有効値との差分が500kW超）
- **補正処理**:
  - 上記いずれかに該当した場合、その1分値は破棄し、**直前の有効測定値（`lastValidValue`）を採用**する（ファイル先頭等で直前値が存在しない場合は `0.0`）。

## 2. KPI・原単位算出仕様

### 2.1 操業3モード分類

生産実績との比較において、操業状態を3つのモードに分類して原単位を算出する。

| モード記号 | 操業モード名称 | 対象稼働時間 (h) | 考慮するステップコード |
|:---:|:---|:---:|:---|
| **A** | **水運転＋実充填** | $T_w + T_f$ | ステップ大分類 20（水運転）＋ 30（実充填） |
| **B** | **水運転のみ** | $T_w$ | ステップ大分類 20（水運転） |
| **C** | **実充填のみ** | $T_f$ | ステップ大分類 30（実充填） |

### 2.2 原単位計算式

- **電力消費原単位 (kWh/本)**:
  $$\text{EnergyIntensity} = \frac{\text{対象期間の総電力量 (kWh)}}{\text{総生産本数 (本)}}$$

- **電力コスト原単位 (円/本)**:
  $$\text{CostIntensity} = \text{EnergyIntensity} \times \text{電力量単価 (円/kWh)}$$
  ※ 電力量単価は、エネルギー計算表から自動取得：
  $$\text{電力量単価} = \frac{\text{電気料金請求金額 (円)}}{\text{使用電力量 (kWh)}}$$

- **充填時電力原単位 (実充填モード時)**:
  $$\text{FillingIntensity} = \frac{\text{充填工程電力 (kWh)}}{\text{実充填時間 (h)}} \quad (\text{kW換算})$$

## 3. クライアント側主要モジュール仕様

### 3.1 `CsvParser` (`gas_app/js/etl/csvParser.js`)
- `detectTagType(fileName, sampleLines)`: ファイル名文字列およびヘッダー行から tag02〜tag07 を自動判別。
- `extractKwColumns(lines, tagType)`: 電流列等を除外し、有効電力列のみを抽出。外れ値（$\ge 1,000\text{ kW}$、$\Delta > 500\text{ kW}$）を直前値に自動置換。
- `parseSingleFile(fileContent, fileName)`: 日別生ファイル（`AQYYYYMMDD_*.TXT`）を含む個別ファイル解析。
- `mergeDailyFiles(fileMap)`: 日別ファイル群を日付・時刻キーで一括結合。
- `groupFilesByYearMonth(fileList)`: 複数月・年次一括投入時に、年月（YYYYMM）ごとにファイルをグループ化。

### 3.2 `HourlyAggregator` (`gas_app/js/etl/hourlyAggregator.js`)
- `aggregateHourly(mergedRecords, yearMonth)`: 01分締めグルーピング、ROUND(AVERAGE, 1)計算、月末パディングを実行し、月間全時間行（744行等）を生成。

### 3.3 `CategoryService` (`gas_app/js/services/categoryService.js`)
- `aggregateCategories(hourlyRows, monthlySums)`: チラー、調合抽出、供給、充填、包装、総電力の各工程小計（1時間・日別・月間）および操業時間を算出。

### 3.4 `KpiService` (`gas_app/js/services/kpiService.js`)
- `calculateKpi(categoryTotals, operationTimes, productionData, electricityData)`: 操業3モードごとの原単位・コストを算出し、評価オブジェクトを返却。

### 3.5 `AnnualService` (`gas_app/js/services/annualService.js`)
- `aggregateAnnualData(monthlyDataMap)`: 8大品種別（2.0L〜280mL）の電力量・生産本数・操業時間を集計し、8大指標の年間月別マトリクスおよび期中累計を計算。
- `aggregateEquipmentSummary(monthlyHourlyRows)`: 受電盤、コンプレッサー、動力盤等の主要設備ごとの年間月別電力量推移および比率を算出。

### 3.6 `ExcelReader` (`gas_app/js/etl/excelReader.js`)
- `parsePetMonthlyReport(buffer, yearMonth)`: SheetJSを用いて月報PETから品種別および月間生産本数を抽出。
- `parseEnergyCalculationTable(buffer, yearMonth)`: SheetJSを用いてエネルギー計算表から電気使用量・請求額・単価を抽出。

## 4. バックエンド仕様 (`gas_app/Code.gs`)

### 4.1 `doGet(e)`
- SPAアプリケーションのHTML（`index.html`）を返却。

### 4.2 `doPost(e)`
- クライアントから送信された集約済みJSONデータを受信し、アクションに応じて処理を実行：
  - `syncHourlyData`: `1時間集計`、`日別集約`、`KPI評価`、`品種別集約` の各シートへ日時キーおよび対象年月キーで差分更新・追記（Upsert）。
  - `getAnnualData`: スプレッドシートに保存済みの年間月別データおよび品種別データを取得・返却（画面の自動復元）。
- 大量書き込み時のパフォーマンス最適化のため、2次元配列による一括書き込み（`setValues`）を使用。
