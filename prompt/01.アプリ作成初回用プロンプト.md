# アプリ概要
アプリの要件定義と構築手順のドラフト版がplan_draftフォルダにありますので、確認してください

# 重要
実際の作成は「Claude code」or「Gemini」で実装
コードは書かずに、タスクと実装計画を作成する

# 仕様
詳細な実装計画を記載した新しいフォルダを作成
「Claude Code」or「Gemini」がそれを読み込み、コードを書き、実行する

# プロジェクトファイル
プロジェクトファイルは「エネルギー使用量集計」以下になります
そのフォルダ内にplanフォルダを作成し、その中に詳細な実装計画のファイルを作成してください

# 注意
計画書には、後でプロンプトを修正する際に必要な情報を記載してください
